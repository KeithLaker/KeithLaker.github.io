# Autonomous AI Database demo experience

A static, offline-friendly feature explorer for Oracle AI World.

## Pages

- index.html is the home page, with index cards for eight feature categories.
- categories/ contains a separate index page for each category.
- features/ contains one guide per feature, with detail, presentation references, slide graphics and available demos.
- The category navigation and feature search remain available on every page.

Open index.html in a browser, or serve this folder with any static web server. No build step or remote service is required.

## Media

Presentation graphics are rendered, local JPEGs in assets/slides/. Video players load the ten unique extracted clips from the Oracle Object Storage folder https://objectstorage.uk-london-1.oraclecloud.com/n/adwc4pm/b/AIW-2026/o/ when the visitor presses play. The identical Data Science Agent clip found in both decks is referenced once.

Slides explicitly marked confidential and shared under NDA in the supplied decks were excluded from the public-facing app and slide images.
